Markdown 변경은 PR에서 검토합니다. 완료 증거를 인용할 때는 `dev`의 움직이는 링크와 함께 전체 커밋 SHA로 고정한 파일 링크를 남깁니다. Confluence에 코드·로그 전체를 복사하는 대신 해당 PR·파일·실행 링크를 기록합니다.

로컬에만 있는 초안은 GitHub에 게시된 문서로 취급하지 않습니다. 추가 공개는 내용·현재 일정·접속 정보 포함 여부를 확인한 PR로 진행합니다.
