# [SCRUM-번호] 변경·검증 기록

- 기록 상태: 작성 중 / 확인 완료
- Jira: https://tlals0028.atlassian.net/browse/SCRUM-번호
- GitHub 이슈 / PR: 링크
- 회의·설계·결정 근거: Confluence 또는 문서 링크
- 기록자·확인자·확인 일시(시간대 포함): 입력

## 변경 이유·범위

목표, 변경 전후 동작, 영향받는 업무·파일·데이터와 남은 작업을 적습니다.

## 실행·검증 결과

| 환경·입력·재현 절차 | 기대 결과 | 실제 결과 | 근거·후속 Jira |
|---|---|---|---|
| 입력 | 입력 | 미실행 / 성공 / 실패 | Actions run·job/PR·화면 링크 |

## 머지·문서·복구 근거

- base / head: 입력
- 실제 머지 시각 / 머지 커밋 전체 SHA: 미병합이면 미병합으로 기록
- 검증 기준 커밋 전체 SHA / 실행 URL·run ID: 입력
- 변경 Markdown의 커밋 고정 링크: 입력
- 남은 문제·수용/이월 결정·복구 방법: 입력

비밀번호·토큰·DB 접속 정보·개인정보가 담긴 원본 로그는 이 문서에 붙여 넣지 않습니다. Jira 완료 여부는 위 검증·완료 기준에 따라 판단합니다.
